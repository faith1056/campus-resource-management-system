# Campus Resource Management System

A Python command-line application for managing campus resources, borrowing, returns, inventory, and reports.

## Features

- Add and manage campus resources
- Prevent duplicate resource IDs
- List resources and their availability
- Borrow resources with quantity validation
- Return borrowed resources
- Prevent invalid returns
- Search resources by name
- Filter resources by category
- View borrowing records
- Generate inventory reports
- Track currently borrowed resources
- Save and reload data using JSON persistence
- Case-insensitive searching and resource IDs

## Technologies

- Python 3
- JSON
- Python Standard Library
